# Network Effects

The network effect is a phenomenon in which the value of a product or
service increases as the number of users or participants grows — the
more people use it, the more valuable it becomes to each individual
user. It's often called "Metcalfe's Law," after Robert Metcalfe, the
inventor of Ethernet.

## Key types

- **Direct network effects** — value increases directly as more users
  join. Social media platforms like Facebook and LinkedIn are classic
  examples.
- **Indirect network effects** — value increases as more complementary
  products or services are developed around the platform. A game
  console like the Xbox or PlayStation becomes more valuable as more
  developers create games for it.

## Strategic consequences

Network effects can create significant barriers to entry for
competitors: when a product has a large user base, competitors
struggle to gain a foothold, since users are unlikely to switch to a
smaller, less valuable alternative. This dynamic can produce
winner-takes-all markets, where the value tied directly to user count
gives the largest player a compounding advantage.

## Common pitfalls

- **Assuming any product with users automatically has network effects**
  — value has to genuinely increase *because of* other users, not just
  correlate with a growing user base; many products scale without any
  real network effect.
- **Ignoring negative network effects** — some networks become less
  valuable as they grow (congestion, spam, declining content quality);
  not every network effect is purely positive indefinitely.
- **Underestimating the cold-start problem** — a product relying on
  network effects has little value with few users, making the earliest
  growth phase the hardest to sustain, before the effect has enough
  scale to become self-reinforcing.
