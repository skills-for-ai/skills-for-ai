# Microsoft PowerPoint

Microsoft PowerPoint is a presentation application for creating slide-
based visual aids — part of the [[microsoft-office]] suite, and the
dominant tool for business, academic, and conference presentations.

## Core capabilities

- **Slide masters and layouts** — templates controlling a presentation's
  consistent visual structure (backgrounds, placeholder positions,
  fonts) across every slide, edited once and applied everywhere, similar
  in spirit to [[microsoft-word]]'s styles.
- **Animations and transitions** — controlling how elements appear
  within a slide (animations) and how the presentation moves between
  slides (transitions) — best used sparingly, since overuse tends to
  distract from rather than support the content.
- **Speaker notes** — a private per-slide notes area visible to the
  presenter (in Presenter View) but not the audience, for talking points
  and reminders.
- **Designer** — an AI-assisted feature suggesting layout and visual
  design improvements for a slide's content automatically.

## PowerPoint vs. pitch deck content

PowerPoint is the tool; [[pitch-deck]] is a specific genre of
presentation content and structure (problem, solution, market, traction,
ask) commonly built in PowerPoint (or an equivalent tool) but distinct
from it — the same tool applies equally to a sales deck, a training
presentation, a conference talk, or a pitch deck, each with different
content and structural conventions.

## Common pitfalls

- **Slides overloaded with text** — a slide meant to support a spoken
  presentation that instead tries to stand alone as a full document
  tends to compete with, rather than support, the speaker.
- **Inconsistent formatting from not using slide masters** — manually
  formatting each slide individually rather than through the master/
  layout system makes the whole deck harder to keep visually consistent
  and expensive to update.
- **Overusing animations and transitions** — flashy slide transitions
  and animations used throughout a deck tend to distract from content
  rather than clarify it; used sparingly, they can genuinely help guide
  attention.
- **No speaker notes for a presentation someone else will deliver** — a
  deck handed off without notes forces the new presenter to reconstruct
  the intended talking points from the slides alone.
