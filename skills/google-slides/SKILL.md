# Google Slides

Google Slides is a cloud-native presentation application — part of
[[google-drive]]/Google Workspace, and Google's counterpart to
[[microsoft-powerpoint]], built around real-time collaborative editing.

## Core capabilities

- **Themes and layouts** — templates controlling a presentation's
  consistent visual structure across every slide, the same underlying
  concept as PowerPoint's slide masters.
- **Real-time co-editing** — multiple people editing the same
  presentation simultaneously, including simultaneously editing
  different slides in the same deck.
- **Speaker notes** — a private per-slide notes area for the presenter,
  visible in presenter view but not to the audience.
- **Transitions and animations** — the same slide-to-slide and within-
  slide motion concepts as PowerPoint, best used sparingly for the same
  reasons.

## Common pitfalls

- **Slides overloaded with text** — the same core presentation-design
  pitfall as PowerPoint: a slide meant to support a spoken presentation
  shouldn't try to stand alone as a full document.
- **Assuming exact fidelity importing/exporting `.pptx`** — complex
  formatting, animations, and fonts can shift when converting between
  Google Slides and PowerPoint format.
- **Presenting directly from an editable, shared link** — presenting
  from a link that also grants edit access risks an audience member
  accidentally (or deliberately) modifying the deck live; use
  view-only sharing or presenter mode for the live presentation.
- **No speaker notes for a deck someone else will deliver** — the same
  handoff problem as PowerPoint: notes need to travel with the deck.
