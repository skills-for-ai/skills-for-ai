# Ishikawa Diagram

An "Ishikawa diagram" is the same technique as a
[[cause-and-effect-diagram]] — named after its creator, quality-
control expert **Kaoru Ishikawa**. See [[cause-and-effect-diagram]]
for the technique covered in full depth (the 6M cause categories, running
the brainstorming process, and common pitfalls) — this entry exists
because "Ishikawa diagram" is one of three common names for the
identical tool, alongside "cause-and-effect diagram" and
[[fishbone-diagram]].

## Why the name varies

All three names describe the same technique: "Ishikawa diagram" names it
after its creator, "cause-and-effect diagram" names it by function, and
"fishbone diagram" names it by its visual fish-skeleton shape. None
implies a different method or a different set of pitfalls — apply exactly
the discipline [[cause-and-effect-diagram]] describes regardless of
which name a team or document happens to use.
