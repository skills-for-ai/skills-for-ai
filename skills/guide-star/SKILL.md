# Guide Star

A "guiding star" is the same underlying idea as a **North Star**: a
single, overarching goal that orients a team or organization's
decision-making, kept deliberately singular so it can actually resolve
competing priorities rather than adding another one. See
[[north-star]] for this concept covered in full depth (including
the Airbnb "nights booked" worked example, its relationship to
[[big-hairy-audacious-goal]] and [[objectives-and-key-results]],
and the vanity-metric pitfall) — this entry exists because some teams and
frameworks use "guiding star" (rather than "North Star") as the name for
the identical concept.

## Why the same idea has two names

Both metaphors point at the same navigational image — a fixed reference
point used to orient movement when the immediate path is unclear or
contested. Neither name implies a different mechanism or a different set
of pitfalls; a team using "guiding star" language should apply exactly
the same discipline [[north-star]] describes: pick one metric or
objective, tie it genuinely to real value (not an easily-gamed proxy),
and use it to resolve — not multiply — competing priorities.

## When this naming shows up

"Guiding star" (or "guide star") tends to appear in team-level or
product-level framing more often than "North Star," which is more common
in growth/product-metrics contexts (à la Airbnb's "nights booked").
Functionally, treat them as interchangeable unless a specific
organization has defined a real distinction between the two terms in its
own documentation.

## Common pitfalls

Identical to [[north-star]]'s: picking an easily-moved metric that
doesn't reflect real value, naming more than one simultaneous "guiding
star" (which defeats the purpose of having a single orienting reference),
and setting one that's never revisited as the team or business model
evolves.
